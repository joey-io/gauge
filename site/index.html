why this exists

Subscription plans meter you in five-hour windows and weekly caps, but they don't show you the meter. The allowance just runs out. People cope by keeping hand-written logs of their remaining percentage.

gauge is the meter. It prices your real usage at Anthropic's published API rates, so a flat subscription becomes a number you can watch: this five-hour window cost $36, this week cost $858, that overnight agent run was $12 of it.

how it counts
source
The transcripts Claude Code already writes to ~/.claude/projects. gauge adds no hooks and changes nothing.
dedupe
Transcripts repeat each message once per streamed chunk and replay them on session resume. gauge counts each API message once, by message id.
subagents
Agent transcripts nest deep in the session tree. gauge walks all of it — in testing they held about half the spend.
pricing
API-list-equivalent dollars, cache reads and writes included. It's a measure, not your bill — plans don't publish quota mechanics, so list price is the honest common currency.
privacy
No network calls, no account, no telemetry. The only thing gauge writes is its own cache in ~/.cache/gauge.
install
npx github:joey-io/gauge

It's a command-line tool, not a service — this page is just the brochure. Needs Node 22.5+ (zero dependencies; it uses the built-in sqlite). The first run scans your history, about a minute per gigabyte; after that it's incremental. Source on GitHub.
